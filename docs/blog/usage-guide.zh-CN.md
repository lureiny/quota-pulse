# 一眼盯住你的 sub2api 额度:quota-pulse 使用与配置指南

如果你在用 [sub2api](https://github.com/Wei-Shaw/sub2api) 聚合多个 Claude / Gemini 账户,大概率会反复打开它的后台,就为了看一眼"这个号的 5 小时窗口快满了没""周配额还剩多少"。**quota-pulse** 把这件事从浏览器里搬了出来——它常驻在 **macOS 菜单栏 / Windows 系统托盘**,点一下弹出毛玻璃面板,所有账户的用量窗口一目了然。**纯只读**,绝不改动上游任何东西。

> 重活由共享的 **Go** 核心扛;UI 是共享的 **Flutter** 包;每个平台只是一层薄壳。macOS 住在**菜单栏**,Windows 住在**系统托盘**。

![主面板总览](./images/01-hero.png)

> 📸 **截图 01 · 主面板总览** — 点开后的毛玻璃面板,2~3 个账户,每个带状态点 + 5h/7d 用量条(最好凑齐一个绿、一个琥珀、一个红,体现颜色分级)。这张作为文章封面。

本文不堆配置表(那是 [README](../../README.zh-CN.md) 的活),而是带你过一遍**每一项设置开/关到底有什么不同效果**,看完你就知道该怎么调成自己顺手的样子。

## 一、装好,连上后台

从 [Releases](https://github.com/lureiny/quota-pulse/releases) 下载:

- **macOS** — `quota_pulse.dmg`,拖进 Applications。ad-hoc 签名,首次启动**右键 → 打开**绕过 Gatekeeper。
- **Windows** — `quota_pulse-windows.zip`,解压即用,绿色免安装。SmartScreen 告警就**更多信息 → 仍要运行**。

第一次打开是空的。进**设置**,填一个 sub2api 实例:**名称 + Base URL + 一个管理员 API key**,点**保存并连接**。

![首次连接](./images/02-first-connect.png)

> 📸 **截图 02 · 首次连接(三连图或拼图)** — ① 空状态面板;② 设置页里填好实例名 / Base URL / API Key 的表单(API Key 用显/隐切换那个眼睛图标);③ 点完"保存并连接"后,面板刷出账户列表。

连上之后,后台默认每 **60 秒**自动读一次 sub2api 缓存,你什么都不用管。

> 💡 **多个后台**:点"添加 sub2api"可以配任意多个实例,各自独立的名称 / URL / Key。每个账户以 `实例|账户ID` 为键,两个后台下相同的账户 ID 也**不会串号**。实例名是**超链接**,点它直接用浏览器打开那个后台。

## 二、主面板:一行能看出多少信息

先认识一下主面板的每一行,后面讲配置时才知道改的是哪儿。

![主面板单行解剖](./images/03-row-anatomy.png)

> 📸 **截图 03 · 单行解剖(带标注箭头)** — 放大一个展开的账户行,标出:① 左侧**状态圆点** + 账户名 + **订阅徽标**(FREE/PRO/ULTRA);② 每个窗口一根**用量条**(标签 + 粗体百分比 + 进度条);③ 行底的**平台 · id · 更新时间**;④ 鼠标悬停时右侧冒出的**刷新按钮**。

几个关键点:

- **状态圆点(账户健康度)**:🟢 正常 · 🟡 预警 · 🔴 限流 · ⛔ 禁用 · 🚫 封禁 · 🔑 待重认证 · ⚪ 错误。被 sub2api 因限流自动停用的号**照常显示**(状态点告诉你它被限了),不会被悄悄丢掉。
- **用量条颜色(利用率分级)**:**≤80% 绿 / 80–99% 琥珀 / ≥100% 红**。注意这跟状态点是**两个独立维度**——一个讲"号还健不健康",一个讲"这个窗口用了多少"。
- **更新时间**:显示的是 **sub2api 那份用量快照的采样时刻**,不是本地拉取时刻。如果某账户最近没真实流量,这个时间会偏旧——因为服务端那份缓存本就没更新(细节见 [`docs/sub2api-usage-cache.md`](../sub2api-usage-cache.md))。
- 点一行**展开**看该账户全部窗口;桌面端**悬停**冒出刷新按钮,强制回源。

## 三、配置详解:不同配置,不同效果

下面是正题。设置页从上到下的分区是:**实例 → 启动 → 列表布局 → 主题 → 托盘悬停内容 → 重置时间 → 用量提醒 → 后台拉取 → 菜单栏滚动(macOS) → 悬浮窗口(Windows)**。我按"看得见的效果"重新归类来讲。

> 除了"实例编辑"需要点**保存并连接**才生效,其余几乎所有项都是**改完即时生效**——可以一边拖一边看面板变化。

### 3.1 列表布局:分组 vs 标签页

多个后台时,账户列表怎么排。

| 取值 | 效果 |
|---|---|
| **分组**(默认) | 每个实例一个标题,账户竖着平铺在标题下,一屏看全 |
| **标签页** | 每个实例一个 Tab,点 Tab 切换,适合实例多、想分开看 |

![列表布局对比](./images/04-layout.png)

> 📸 **截图 04 · 列表布局对比(左右并排)** — 左:分组模式(两个实例标题 + 各自账户);右:标签页模式(顶部 Tab 栏,当前 Tab 的账户)。

### 3.2 主题:浅色 / 深色 / 跟随系统

毛玻璃面板的明暗。默认**跟随系统**。强调色取**系统强调色**。

![主题对比](./images/05-theme.png)

> 📸 **截图 05 · 主题对比(左右并排)** — 同一份账户列表,左浅色右深色,体现毛玻璃在两种背景下的质感。

### 3.3 显示窗口:5h / 7d,可多选 —— 跨平台生效

这是最影响"信息密度"的一项。你勾选哪些窗口,**菜单栏、托盘 tooltip、悬浮窗**就只展示哪些(主面板始终展示全部窗口,不受此影响)。默认 **5h + 7d 都选**。

| 取值 | 菜单栏 / 悬浮窗单行的样子 |
|---|---|
| **只 5h** | `🟢 账户名 用80% · ⏳重置`(单窗口省略前缀,最简洁) |
| **只 7d** | `🟢 账户名 用85% · ⏳重置` |
| **5h + 7d**(默认) | `🟢 账户名 5h 用80% · 7d 用85% · ⏳重置`(多窗口各加 `5h`/`7d` 短前缀) |

![显示窗口对比](./images/06-windows.png)

> 📸 **截图 06 · 显示窗口对比(三联)** — 同一个账户在菜单栏/悬浮窗里:① 只勾 5h;② 只勾 7d;③ 两个都勾。直观看出文本长度和前缀的差别。

> ⚠️ 至少要保留一个窗口,删到最后一个时会被忽略(不允许全关)。

### 3.4 显示量:用量 % vs 剩余 %

同一个数字,换个说法。默认**用量**。

| 取值 | 文本 |
|---|---|
| **用量**(默认) | `用 80%` —— 我已经用掉了多少 |
| **剩余** | `剩 20%` —— 我还能用多少 |

> 只改数字文本本身,**不影响进度条的长度和颜色分级**(进度条永远按利用率画)。

![显示量对比](./images/07-metric.png)

> 📸 **截图 07 · 显示量对比(左右)** — 同一账户,左"用 80%"、右"剩 20%",其余完全一致。

### 3.5 重置时间:倒计时 vs 绝对时刻

窗口什么时候重置,怎么显示。默认**倒计时**。这个选择对**主页和托盘/菜单栏同时生效**。

| 取值 | 文本 |
|---|---|
| **倒计时**(默认) | `2天3h后重置`、`3h13m后重置`(到"天"级,为 0 时省略天) |
| **绝对** | `06-13 15:42 重置`(具体时刻) |

![重置显示对比](./images/08-reset.png)

> 📸 **截图 08 · 重置显示对比(左右)** — 同一窗口行,左倒计时、右绝对时刻。

### 3.6 菜单栏 / 托盘 / 悬浮窗:每个平台的"常驻一行"

这是 quota-pulse 的灵魂——不点开也能扫一眼。三个平台表面各有脾气。

#### macOS 菜单栏:固定图标 + 像素级滚动

macOS 用自绘的 `NSStatusItem`:**图标固定不动**,后面跟着账户文本;**放得下就静态,放不下就 60fps 像素级丝滑滚动**。两个滑块可调:

- **宽度**(8–40 字,默认 **10**):一次能看到多少字。宽度大到能装下整行,就不滚了。
- **速度**(30–300ms/步,默认 **300**=最慢):越小滚越快。下方实时显示 `≈ X 字/秒`。

> 这两个滑块**只在"全部账户"模式、且一行放不下时**才有意义。

![macOS 菜单栏滚动](./images/09-macos-menubar.gif)

> 📸 **截图/动图 09 · macOS 菜单栏** — 右上角图标固定,后面文字横向滚动展示多个账户。建议录一小段 GIF,或并排放"窄+快"和"宽+慢"两档的静帧对比。

#### Windows 托盘:悬停 tooltip

Windows 托盘图标显示不了文字,改用**悬停 tooltip**:每个(选中的)账户一段——状态 emoji + `实例·账户`,随后每个选中窗口一行缩进;超出长度预算就折叠成 `…还有 N 个`。

![Windows 托盘 tooltip](./images/10-win-tooltip.png)

> 📸 **截图 10 · Windows 托盘 tooltip** — 鼠标停在托盘图标上,弹出的 tooltip 显示 2~3 个账户的 5h/7d 用量,末尾带"…还有 N 个"折叠示意。

#### Windows 悬浮窗:**滚动 vs 多行**(重点)

Windows 还有个**默认开启**的桌面悬浮窗——一条**可拖拽、置顶**的浮条,原生 Direct2D 自绘、带彩色圆点。它有两种模式:

| 模式 | 样子 |
|---|---|
| **滚动**(默认) | **单行**,像素级 60fps 横向滚动,内容跟 macOS 菜单栏同源;放不下就滚,**单账户超宽也滚**。同样有速度/宽度两个滑块。 |
| **多行** | **不滚动**,把托盘 tooltip 的内容铺进浮窗:每账户一个"基础行 +(每个选中窗口一行)"。两窗口都选时正好是 `base / 5h / 7d` 三行,窗口高度自适应。 |

![悬浮窗 滚动 vs 多行](./images/11-win-floating.png)

> 📸 **截图 11 · 悬浮窗两模式对比(左右并排,本文最重要的一张)** — 左:**滚动模式**(右下角细长浮条,单行内容横向流动,可放运动模糊或箭头示意在滚);右:**多行模式**(浮窗铺开 2~3 个账户,每账户基础行 + 5h 行 + 7d 行,行首彩色圆点,重置时间列对齐成一条竖线)。

多行模式的两个细节值得在截图里体现:① 行首圆点是**双维度**的——账户行用**状态色**,窗口行用**用量分级色**;② 各窗口行的重置时间用制表位**对齐成一条竖线**(比例字体下空格对不齐,所以用了 DirectWrite 制表位)。

悬浮窗还有两个开关:

- **全屏时自动隐藏**(默认关):前台应用全屏(游戏/视频/演示)时浮窗自动藏起,退出再显示。
- **重置位置**:浮窗被你拖走后会记住位置;点这个按钮归还到右下角默认位。

![悬浮窗 全屏隐藏 + 拖拽](./images/12-win-floating-behavior.png)

> 📸 **截图 12 · 悬浮窗行为(二联)** — ① 拖拽:鼠标把浮窗从右下角拖到屏幕左侧,松手停住;② 全屏隐藏:一个全屏窗口在前,浮窗消失,退出后又出现。

#### 托盘范围:全部账户 vs 钉住子集

菜单栏/托盘/悬浮窗里**显示哪些账户**。默认**全部账户**。

| 取值 | 效果 |
|---|---|
| **全部账户**(默认) | 所有账户按 `实例·名` 稳定排序全显示 |
| **指定账户(钉住)** | 多选勾出你关心的几个,只显示这几个;一个都没勾时回退显示**最忙的那一个** |

> 账户多的时候,"钉住"能让菜单栏/悬浮窗短下来、不再频繁滚动跳变。

![托盘范围对比](./images/13-scope.png)

> 📸 **截图 13 · 托盘范围对比(左右)** — 左:全部账户(长长一串);右:只钉住 2 个(清爽)。可一并截出设置页里的账户多选 Chips。

### 3.7 用量提醒:别等满了才发现

两类通知,各自独立可配,还能分别选哪些窗口(5h / 7d)触发。

- **超阈值**(默认**开**,5h+7d):用量越过你设的阈值(默认 **90%**)就弹 🚨 *用量告警*;到 ≥100%(限流)升级成 🛑 *额度已满*。
- **额度恢复**(默认**关**):窗口回落到阈值以下时弹 ✅(通常是窗口重置那一刻)。
- **阈值**:50–100% 滑块,默认 **90%**。
- **去重**:每个重置周期、每类只提醒一次(按重置时间 ±10s 容差比较,避免抖动刷屏);**首次快照静默**,启动时不会对已经在高位的号炸一串通知。

设置页有个**发送测试通知**按钮,会依次弹出三种样例(🚨 / 🛑 / ✅),不用等真触发就能验证送达、预览长相。

![用量提醒](./images/14-alerts.png)

> 📸 **截图 14 · 通知样例(拼图)** — 系统通知样式:① 🚨 用量告警「xxx 的 5h 已用 92%」;② 🛑 额度已满;③ ✅ 额度恢复。再配一张设置页通知区(阈值滑块 + 两组窗口 Chips + 测试按钮)。

### 3.8 后台拉取:省心 vs 实时,以及"为什么默认不强制回源"

两档节奏,藏在"后台拉取"分区。

- **刷新间隔(被动读缓存)**:30s / **1m**(默认) / 2m / 5m。读的是 sub2api 已经缓存好的用量,很便宜,**始终开启**,只能调周期。面板打开时会自动提速、电池供电时降速。
- **自动强制回源**:**默认关**。开启后周期性强制 sub2api 回源刷新上游(可选 5m/10m/30m/1h,默认 10m)。

> ⚠️ **为什么默认不开强制回源?** 因为周期性回源有**明显的自动化特征**,可能给上游账号带来风险。所以默认只做"读缓存"这种被动、无痕的动作。**启动首次加载**和你**手动点刷新**仍然会回源一次(不受这个开关影响),所以平时根本不需要开它。

![后台拉取设置](./images/15-polling.png)

> 📸 **截图 15 · 后台拉取设置** — 设置页"后台拉取"区:刷新间隔下拉 + 自动强制回源开关(关),开关打开后下方多出"回源间隔"下拉。

### 3.9 开机自启

登录系统就自动在后台拉起。默认关。

- **macOS**:写用户级 `LaunchAgent`(纯 Dart,无 helper;应用为此**刻意不沙箱**)。
- **Windows**:写一条 `HKCU\…\Run` 注册表项。

## 四、几套推荐组合

不知道从哪开始?直接抄:

**🪶 极简低打扰** — 显示窗口只勾 **5h**、托盘范围**钉住**最关心的 1~2 个号、Windows 用**滚动**模式、通知阈值拉到 **95%**。菜单栏/浮窗短而安静。

**🎯 全盘盯紧** — 显示窗口 **5h+7d**、托盘**全部账户**、Windows 切**多行**模式一眼铺开、刷新间隔 **30s**、超阈值通知 5h+7d 全开。信息最密。

**🛰️ 多后台运维** — 多个 sub2api 实例、列表用**标签页**、托盘**钉住**每个后台的关键号、悬浮窗**多行**常驻一角。

**🎬 演示 / 直播** — Windows 开**全屏自动隐藏**,录屏/投屏全屏时浮窗自动让位,不挡画面。
